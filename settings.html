Firebase Data Structure

SmartStorage/ ├── current │ ├── date │ ├── time │ ├── timestamp │ ├── temperature │ ├── humidity │ ├── float │ ├── int │ ├── string │ └── sensor ├── history/ │ └── date_time_record/ └── status/ ├── wifiConnected ├── sensorConnected ├── temperature └── humidity

For compatibility with the earlier website, float contains temperature and int contains rounded humidity. The main dashboard uses the clearer temperature/humidity fields.

Smart Storage

A web dashboard designed to display data collected by an ESP32 and synchronized through Firebase Realtime Database.

Core Functions

• Start and stop collection

• Realtime record display

• History browsing and clearing

• Data validation alerts

• Summary reports and CSV export

• ESP32 Wi-Fi Manager compatibility

Record Structure

{ "timestamp": "YYYY-MM-DD HH:MM:SS", "int": 1, "float": 10.50, "string": "value_1000" }
